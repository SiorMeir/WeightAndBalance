The problem

Uncertainty multiplies faster than a checklist.

A passenger can be light or heavy, forward or aft. An item can be present or absent. Each tail has its own basic weight-and-balance case. Checking every combination is correct—but it grows exponentially.

2²⁰1,048,576 binary optional-item combinations
4⁴256 real passenger endpoint cases in the included demo
0hull-only violations allowed to reduce a fuel cap
The key insight

Weight and moment add. CG does not.

Work in weight–moment space, where every load is additive. Convex hulls then bound every configuration in a group, allowing the algorithm to certify a whole family with one geometric test.

Model real endpoints

Keep the declared discrete choices: basic-aircraft cases, optional payloads, and each weight/station endpoint.

Build a safe envelope

Minkowski sums combine item hulls. Sweeping that hull through a fuel segment encloses every centrogram in the group.

Certify or refine

A certified hull is pruned. An unresolved hull is split or checked with a real configuration—never guessed unsafe.

How it works

From millions of cases to a defendable answer.

Set a real cap

Evaluate a real configuration to create a candidate safe-fuel upper bound.

Group possibilities

Bound unresolved choices with a convex hull in weight–moment coordinates.

Check the sweep

Test every fuel segment against every envelope edge, including the segment interior.

Prove or split

Prune a safe group; otherwise refine it until a real configuration decides the cap.

The additive foundation

Simple arithmetic. Strong guarantees.

W_total = W_basic + Σ W_item + W_fuel
M_total = W_basic × CG_basic + Σ(W_item × station_item) + M_fuel
CG      = M_total / W_total

configuration hull = P₁ ⊕ P₂ ⊕ ... ⊕ Pₙ
swept hull         = configuration hull ⊕ fuel segment
Technical guide

The complete method, in plain language.

This is the web-rendered version of the project’s algorithm guide. It keeps the safety-critical distinction clear: hulls prove groups safe; only real configurations can reduce the usable-fuel result.

Input contract

  • Use a convex polygon of CG-station and gross-weight vertices; boundary contact is safe.
  • Represent basic-aircraft uncertainty and payload tolerances as finite, real endpoint cases.
  • Store every load in consistent weight–moment coordinates and require positive total weight.
  • Interpolate each supplied fuel flow linearly in weight–moment coordinates.
  • Check the entire centrogram, including the interior of every fuel segment.

Base calculation

  • Sum basic aircraft, selected item, and fuel weights and moments.
  • Recover CG as total moment divided by total weight.
  • Find envelope crossings analytically on every fuel segment.
  • Return the maximum safe prefix of the fuel trajectory.
  • Report an invalid starting state as infeasible, not as a safe zero-fuel cap.

Hull certificate

  • Take the convex hull of each item’s permitted contributions.
  • Combine hulls with Minkowski sums, then add a tail’s basic-aircraft hull.
  • Sweep the result through a clipped fuel segment.
  • Maximize each transformed envelope constraint over every swept-hull edge.
  • Prune only when every constraint is certified safe.

Complexity

  • Exhaustive work is O(T × F × E × kⁿ).
  • One hull pass is O(T × F × E × H).
  • For constant-size choices, 2D hull complexity is linear-scale: H = O(n).
  • Exact branch-and-bound can still be exponential in the worst case.
  • Its payoff is practical pruning with no unsafe shortcut.

Branch-and-bound pseudocode

U = minimum real maximum-safe-prefix from seed configurations
queue = [all permitted item and basic-aircraft choices]

while queue is not empty:
    group = queue.pop()
    if every clipped fuel segment of group’s swept hull is certified safe up to U:
        continue                         # the group cannot lower U
    if group is one real configuration:
        U = min(U, realMaximumSafePrefix(group))
    else:
        optionally evaluate a real witness
        split the unresolved group and add its children to queue

return U

Lean 4 building block

import Mathlib

structure Load where
  weight : ℝ
  moment : ℝ

def contribution (weight station : ℝ) : Load :=
  ⟨weight, weight * station⟩

def cg (load : Load) : ℝ := load.moment / load.weight

theorem contribution_cg
    (weight station : ℝ) (hweight : weight ≠ 0) :
    cg (contribution weight station) = station := by
  dsimp [cg, contribution]
  apply (div_eq_iff hweight).2
  ring
